# Правила работы с проектом

- Разработку и наполнение выполнять локально в ветке `dev`.
- Не менять файлы, контент и базу боевого сервера вручную через SSH, SFTP, PHP CLI или прямое подключение к БД. Наличие доступа из предыдущих задач не разрешает такие изменения.
- Боевой сайт обновляется из репозитория через настроенный GitHub Actions workflow для `main`. Локальная задача не означает запрос на слияние в `main` или публикацию.
- Изменения структуры инфоблоков и первоначальное наполнение оформлять как проверяемые идемпотентные миграции в репозитории. Сохранять последующие изменения контент-менеджеров.
- Дампы БД, загрузки, пароли и настройки локального окружения не включать в Git. Не заменять рабочую базу локальным дампом.
- Разовые действия на сервере допустимы только в пределах прямого запроса пользователя, например для удаления конкретных ошибочно созданных объектов. После такого действия возвращаться к локальной работе.
