Тиззеры первого экрана
====================

В инфоблоке «Услуги» (5) используются две множественные привязки к **элементам** инфоблока «Тизеры» (29):

- `HERO_TIZZERS` — свойство элемента услуги, «Карточки первого экрана».
- `UF_HERO_TIZZERS` — пользовательское поле раздела услуг с тем же названием.

Если выбор пуст либо все выбранные элементы недоступны, показываются активные тиззеры из раздела «По умолчанию» (5158). Выбор раздела не наследуется отдельной услугой. Главная и общий каталог `/services/` используют набор по умолчанию. Выводятся до четырёх элементов по `SORT`, затем `ID`, по возрастанию.

Общие тиззеры находятся только в разделе «По умолчанию», остальные — в корне инфоблока. Один элемент можно выбрать в нескольких услугах и разделах. При изменении тиззеров сбрасывается также кеш родительского компонента услуги.

Миграция для локальной базы:

```sh
php -d short_open_tag=1 local/tools/migrate-hero-tizzers.php
php -d short_open_tag=1 local/tools/migrate-hero-tizzers.php --apply
```

Первый запуск показывает план, второй сохраняет. Реализация доставляется вместе с кодом в `local/php_interface/migrations/hero-tizzers.php`. После успешной публикации и создания резервной копии миграция запускается отдельно через PHP CLI с `--apply`. Обычное обновление файлов её автоматически не запускает.

Миграция создаёт поля, а существующее свойство `HERO_TIZZERS` типа «Привязка к разделам» переводит в множественную привязку к элементам: выбранный раздел заменяется его непосредственными элементами, включая неактивные. Поэтому последующая активация выбранного тиззера продолжит работать. Чужие ссылки на разделы инфоблока 29 блокируют перенос до их обработки.

Тиззеры переносятся в корень, кроме входящих в набор по умолчанию. Пустые прежние разделы удаляются. ID элементов, тексты и сортировка сохраняются. Исходные принадлежности и выбор услуг сохраняются в опции `usticom_tizzers/element_links_v1_plan`. После успешного выполнения повторный запуск ничего не меняет и сохраняет последующие правки контент-менеджеров.
